# Security reports

Do not post credentials, game files, keys, firmware, saves, memory dumps or
unredacted personal paths. For a suspected security vulnerability, use GitHub's
private vulnerability reporting if enabled. Otherwise open an issue requesting
a private contact without including exploit details or sensitive data.

Do not execute downloaded mod programs. The launcher imports RomFS data and does
not support executable mod installers. Report unsafe ZIP extraction, downloads
outside the expected GameBanana hosts, or changes outside the selected staging
folder as security issues.
