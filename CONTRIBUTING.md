# Contributing

Keep changes small and explain what was tested. Preserve inherited copyrights
and licenses. Contributions to this fork are under GPL-3.0-or-later unless an
existing file's separately licensed material requires its original terms.

Never commit games, dumped/derived modules, console keys, firmware, saves, cache
content or game screenshots/artwork. Use synthetic fixtures for tests. Run
`python scripts/audit_public_source.py` before proposing changes. Do not claim
performance or compatibility beyond measured evidence.
